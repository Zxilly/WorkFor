## 安装包与安装往返

portable / Setup 自包含 .NET Runtime 10.0.14 和 Windows App SDK 2.6.4，用户不需 SDK、PowerShell 或 Windhawk。独立工程发布目录避免 DLL 覆盖；启动器对文件清单做 SHA256 校验。

发布验证运行了无项目 DOTNET_ROOT 的实际计薪进程，固定 2026-10-30 11:00 时薪 16 元得到 32.00 元；校验器、原生受控引导和库存清理测试通过。

在事先不存在的当前用户安装目录执行过一次静默安装 / 卸载往返：安装、全包校验、快捷方式和卸载信息创建通过；卸载后文件、快捷方式、卸载信息及正确引用的登录启动命令全部清理。此测试未启动产品、未向 Explorer 加载该安装目录 DLL，未触碰工资数据目录。测试脚本默认只预检，必须显式 `-Execute` 才实际安装。

已 PIN 的任务栏 DLL 仍需 Explorer 自然退出才能物理释放，因此安装器会明确拒绝覆盖仍映射的本产品文件，要求注销后再升级或卸载，不会结束 Explorer。NSIS 路线不宣称具有完整事务式升级回滚。

## 依赖与构建的实际状态

- 运行依赖固定当前稳定版，包含 Jint 4.17.0、Corvus 5.7.9、Windows App SDK 2.6.4。
- .NET SDK 10.0.403、CMake 4.4.5 和 NSIS 3.13 均有项目本地引导与官方校验。
- 本机原生编译器仍是 VS 2022 / MSVC 19.44、Windows SDK 26100，因此包明确标记 `prototype`。严格构建要求 VS 2026 18.11.2、SDK 28000；不能把旧原生工具链说成已满足最新基线。
- 稳定 .NET SDK 的 TFM 检查不接受 28000 TFM，WinUI 实现使用 26100 TFM 并显式引用最新 SDK.NET.Ref 28000.87。
- 未提供签名证书，产物为 unsigned；项目未伪造签名，也未自动接受 WiX 维护费 EULA。
